# Gate changes and passenger communication

## Purpose

This procedure covers what happens when a departure's gate changes at HUB, and how passengers are told.

## Making a gate change

1. The stand planner agrees the new gate with the duty manager.
2. Update the gate in the operations system; the flight information displays update within 2 minutes.
3. Send one notification to booked passengers with the notify_passengers tool, reason "gate_change".
4. Make a public announcement at the old gate and the new gate.
5. Ask the assistance team to move any passengers with reduced mobility.

## Timing

A gate change less than 30 minutes before boarding needs the duty manager's agreement, because passengers may not reach the new gate in time. Do not change the gate of a flight that has started boarding unless the aircraft has moved.

## Messages

Keep the message short: the flight, the new gate, the boarding time. Do not send a second notification for the same gate change; the tool replays the first one.
